# LaserPrep
*unfold your ideas*

Anhand eines 3D-Modells wird eine Laserdatei erstellt.

## Benutzung
`index.html` im Browser öffnen und eine OBJ-Datei auf die Seite ziehen (oder „OBJ-Datei wählen“ klicken).
Zum Ausprobieren liegt ein Testmodell in `beispiel/testhaus.obj`.

## Verwendete Bibliotheken
- [three.js](https://threejs.org) r160 – 3D-Darstellung und OBJ-Import, MIT-Lizenz
